# DroppShipping

Step 1: Install dropp-shipping:
## NPM
````bash
npm i dropp-shipping
````
Step 2: Include a theme:

`in the project Global style import :`
````bash
@import 'dropp-shipping/src/lib/styles';
@import "@ng-select/ng-select/themes/default.theme.css";
````
step3: import essentail files:
```bash
DroppShippingComponent 'from' import {DroppShippingComponent} from 'dropp-shipping'
````
